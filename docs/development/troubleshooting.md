# Troubleshooting

| Symptom                                                                                             | Cause                                             | Fix                                                                                                                                   |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `cargo test` exits with `STATUS_ENTRYPOINT_NOT_FOUND` (Windows)                                     | Test binary lacks the Common-Controls v6 manifest | Already handled in `src-tauri/build.rs`. If it reappears, check that `windows-app-manifest.xml` exists and `cargo clean -p ripemongo` |
| Frontend call fails with "... not allowed" / `IPC_FAILURE`                                          | Command not in `APP_COMMANDS` or capability       | Add it to `src-tauri/build.rs` and `capabilities/default.json`                                                                        |
| `bindings.ts` out of date / CI diff check fails                                                     | Rust IPC types changed                            | `pnpm bindings` and commit the result                                                                                                 |
| Vitest: `Failed to start forks worker` / undici error                                               | jsdom ≥ 30 requires Node ≥ 22.22                  | Keep jsdom on 27.x or upgrade Node                                                                                                    |
| `tsc`: `baseUrl is deprecated`                                                                      | TypeScript 6 deprecation                          | Use `paths` without `baseUrl` (already done)                                                                                          |
| `cargo fmt` not found                                                                               | rustfmt component missing                         | `rustup component add rustfmt clippy`                                                                                                 |
| Port 1420 already in use                                                                            | A previous `pnpm app:dev` is still running        | Stop it; the port is fixed (`strictPort`)                                                                                             |
| Blank window on Linux                                                                               | Missing WebKitGTK                                 | Install the packages from getting-started.md                                                                                          |
| Theme looks wrong after editing `settings.json` by hand                                             | Invalid JSON                                      | Fix or delete the file; defaults are used                                                                                             |
| Editor dialog makes the window go blank; Vite logs `Cannot assign to read only property 'toString'` | Monaco under Tauri `freezePrototype`              | Re-create `patches/monaco-editor@*.patch` for the new version, delete `node_modules/.vite`, restart `pnpm app:dev`                    |
