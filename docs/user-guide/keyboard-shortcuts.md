# Keyboard shortcuts

On macOS, use **⌘** where this page says **Ctrl**, except for switching tabs. The tab shortcuts
do nothing while a dialog is open, so they never change what is behind it.

| Action                                       | Windows / Linux     | macOS              |
| -------------------------------------------- | ------------------- | ------------------ |
| Open the command palette                     | Ctrl+K              | ⌘K                 |
| Close the current tab                        | Ctrl+W              | ⌘W                 |
| Next tab                                     | Ctrl+Tab            | ⌃Tab               |
| Previous tab                                 | Ctrl+Shift+Tab      | ⌃⇧Tab              |
| Move between tabs (tab bar focused)          | ← / →               | ← / →              |
| Connect to the selected connection (sidebar) | Enter               | Enter              |
| Go to a collection                           | Ctrl+P              | ⌘P                 |
| Filter the sidebar                           | Ctrl+Shift+F        | ⌘⇧F                |
| Move between sidebar rows                    | ↑ / ↓               | ↑ / ↓              |
| Close a dialog or menu                       | Esc                 | Esc                |
| Run the query (query bar)                    | Enter               | Enter              |
| Find on this page (collection tab)           | Ctrl+F              | ⌘F                 |
| Next / previous match (find bar)             | Enter / Shift+Enter | Enter / ⇧Enter     |
| Show query suggestions                       | Ctrl+Space          | ⌃Space             |
| Choose / accept a suggestion                 | ↑ ↓ / Enter or Tab  | ↑ ↓ / Enter or Tab |
| Save in the document editor                  | Ctrl+Enter          | ⌘Enter             |
| Preview a bulk update                        | Ctrl+Enter          | ⌘Enter             |
| Edit the focused field value (List view)     | Enter or F2         | Enter or F2        |
| Save / cancel an inline field edit           | Enter / Esc         | Enter / Esc        |

Every action is also available from the command palette, so you only need to remember
**Ctrl+K**.
