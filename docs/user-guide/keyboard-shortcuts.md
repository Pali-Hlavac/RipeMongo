# Keyboard shortcuts

On macOS, use **⌘** where this page says **Ctrl**, except for switching tabs.

| Action                                       | Windows / Linux | macOS |
| -------------------------------------------- | --------------- | ----- |
| Open the command palette                     | Ctrl+K          | ⌘K    |
| Close the current tab                        | Ctrl+W          | ⌘W    |
| Next tab                                     | Ctrl+Tab        | ⌃Tab  |
| Previous tab                                 | Ctrl+Shift+Tab  | ⌃⇧Tab |
| Move between tabs (tab bar focused)          | ← / →           | ← / → |
| Connect to the selected connection (sidebar) | Enter           | Enter |
| Close a dialog or menu                       | Esc             | Esc   |

Every action is also available from the command palette, so you only need to remember
**Ctrl+K**.
