# RipeMongo user guide

RipeMongo is a desktop app for working with MongoDB databases. You can browse and edit data,
run queries and aggregations, manage indexes, and back up or restore databases without using
the command line.

This guide explains how to use the app. It grows with every release; pages for features that
are not available yet are listed at the bottom.

## Contents

- [Getting started](getting-started.md): install RipeMongo and connect to your first database
- [The interface](interface.md): sidebar, tabs, command palette, themes
- [Connections](connections.md): save, organize, secure and share connections
- [Databases and collections](databases-and-collections.md): browse, create, rename and drop
- [Finding connections and collections](search.md): filter the sidebar by name, jump to any
  collection, find text on the page
- [Viewing documents](documents.md): list, JSON and table views, paging, copying
- [Finding documents](querying.md): filters, suggestions, sort and projection, history
- [Editing documents](editing-documents.md): insert, edit, clone and delete documents, or
  update and delete many at once
- [Backing up and restoring](backups.md): save a server, database or collection, run saved
  dumps again, restore a dump, follow the progress
- [Exporting and importing](import-export.md): save a collection as a JSON or CSV file, or
  add documents from one
- [Copying data](copying.md): copy a database or collection to another connection, or within
  one
- [Keyboard shortcuts](keyboard-shortcuts.md)

## Coming later

Aggregations, indexes, schema analysis

## Getting help

If something does not work, the error message in the app tells you what went wrong and what to
try next. For anything else, contact the RipeMongo maintainers.
